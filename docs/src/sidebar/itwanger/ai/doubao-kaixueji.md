以前开学的第一件事是领教材。

现在开学的第一件事是领Token。

哈哈。

这不，开学季豆包搞了个活动，在校大学生只要完成学生认证，就免费送 3 个月豆包工作会员。原价 68 块一个月的，直接白送三个月，一分钱不花。

我一个老登是真羡慕了呀。

啧啧啧。

还有，每完成一个小任务，比如说整理学习材料、创建新学期计划，还能额外获得一次重置机会。

![](https://cdn.paicoding.com/stutymore/doubao-kaixueji-20260904155648.png)

领完会员，用【豆包工作】干什么事呢？

我觉得AI时代，必须要做的一件事，就是给自己制定一个为期两个月的 Agent 岗位求职计划。

毕竟对于学生党来说，用 Agent 除了提高学习效率之外，最重要的就拿下一份称心如意的offer，AI/Agent研发工程师是最好的。

那刚好我之前整理过一份学习路线，这次就利用【豆包工作】制作成精美的PPT分享给大家，照着做。

SSP offer 就是你的！

打开豆包桌面版，选择【工作】进入【豆包工作】模式，技能选择PPT，工作任务可以选云电脑。

![](https://cdn.paicoding.com/stutymore/doubao-kaixueji-20260904160820.png)

由于豆包是多端同步的，所以我们在手机上也可以随时看到进度。

![](https://cdn.paicoding.com/stutymore/doubao-kaixueji-f966a4304a5f05796e89e3dcc5860047.jpg)

和以前用的那些对话型 AI 不一样。对话型 AI 只能回答你「怎么准备秋招」，给你一堆文字建议，然后你自己去排版、自己去做表格、自己去画时间线。豆包工作是直接帮你把活干了，你要 PPT，它就给你一份能打开能编辑的 PPT。

好，等豆包工作读取完学习路线后，就可以调用 PPT 的 Skill 开始生成第一页内容了。

>提示词参考：我有一份 AI Agent 学习计划，你能帮我制作成杂志风的 PPT 吗，要求为期两个月，让我能够按部就班的去冲刺 Agent 研发岗位，比如说拿下字节的 ssp offer：https://t.zsxq.com/fThmr 你可以直接用浏览器打开查看内容，要求目标清晰，路线清晰，能够把重点划出来，可执行

![](https://cdn.paicoding.com/stutymore/doubao-kaixueji-20260904162148.png)

不知道大家什么感觉，我是真喜欢这个杂志的风格，视觉鲜艳但又很有设计感。

让人看完就是赏心悦目。

所有用到PPT制作的地方我都建议大家在Prompt上加上【杂志风】这个关键字。

哪个元素需要调整可以直接在工作台编辑。

![](https://cdn.paicoding.com/stutymore/doubao-kaixueji-20260904162546.png)

整个PPT零抽卡，注意看这一页。

![](https://cdn.paicoding.com/stutymore/doubao-kaixueji-20260904162915.png)

AI 应用开发的四层能力，分别是：

- 第一层是工程基础，Java/Spring Boot/MySQL/Redis/Kafka 这些大部分同学已经学了，只需要在微服务组件的底层原理方面加深一下就可以了。
- 第二层是 AI 核心概念，大模型原理、Token 和上下文窗口、Embedding 和向量检索、Prompt 工程、幻觉的成因和缓解方式。
- 第三层是 AI 应用开发的核心技术，RAG 全流程、Agent 核心范式（ReAct 推理、Tool Calling、MCP 协议）、工作流编排、流式输出、多轮对话管理。这一层通过做项目来建立核心竞争力。
- 第四层是 AI 工程化能力，调用链追踪、效果评测、性能优化。这是从会用到用好的进阶。

可以说参考意义极大，基本上你学AI应用开发，就是这些东西。

除了做 PPT，日常学习中也有不少场景用得上。

比如把一整章教材的内容丢给它，让它整理成复习卡片。或者把 JD 和自己的经历粘贴进去，让它生成一份针对这个岗位的定制简历。

领取步骤很简单。

1. 下载「豆包」电脑端 `https://www.doubao.com/download/desktop`
2. 点左下角「我」→「开学免费送 3 个月」
3. 完成学生认证（姓名 + 学校 + 学历，学信网核验）
4. 认证通过，会员自动到账

![](https://cdn.paicoding.com/stutymore/doubao-kaixueji-20260904164550.png)

对了，认证完还能领 1 次额度重置机会，邀请同学一起下载豆包电脑端，双方各得 1 次额度重置。
