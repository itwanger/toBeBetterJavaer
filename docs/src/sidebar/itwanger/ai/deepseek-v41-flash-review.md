![](https://cdn.paicoding.com/stutymore/new-qoder-20260907092104.png)

是不是非常抽象？

但 V4.1 Flash 就很顶了，我录了个屏，大家感受一下。

真的，有点让我不敢相信，这是 0.1 个版本的提升。

就好像上个学期你的同桌还是个学渣，这个学期突然就考到班级前三名了。

GPT-6 Astra 作为裁判打了 6.5 分。鱼、水草、鹅卵石、荷叶和水光都有，鱼体会弯曲，投食后确实会聚拢进食；拨水、暂停、重置也能正常使用。

提示词：

```

点击水面投放鱼食并产生涟漪，附近的鱼会转向、加速聚拢，吃完后散开；拖动鼠标能拨动水面。提供投食提示、暂停和重置，画面安静、精致、适合全屏展示。
```

## 04、实时二维彩色流体

【录屏】

这个让我直接闭嘴了。

单个 HTML 文件，零依赖，零第三方库，但它跑的是真正的 Navier-Stokes 方程。鼠标拖动注入染料和推力，不同颜色在同一个速度场里对流、卷曲、混合。

网格上的流体模拟，每一步都在 GPU 上跑平流、压力求解、涡旋约束。涡旋、力度、消散三个参数同时拉到最大，持续涂抹 30 秒，求解器仍然能保持稳定。

```
在新目录 ds41-fluid 中，用单个 HTML 和原生 JavaScript/WebGL 实现实时二维彩色流体。黑色背景上，鼠标按住拖动会注入染料和推力，形成连续卷曲、相互混合、逐渐消散的烟雾漩涡；不同位置注入的颜色能互相影响。
实现基于网格的流体求解，不用现成流体库，也不用粒子尾迹冒充。提供颜色、消散速度和涡旋强度控制，以及暂停、清空、触屏拖动。
直接写出完整代码，实际运行检查交互、窗口缩放和持续操作时的稳定性，交付 HTML、运行方式和已知限制。
```

## 05、暴力摩托

90 年代的《暴力摩托》（Road Rash），多少人的童年，上次用 Qoder 做过一版，有同学留言说，玩过的都 50 多岁了。

我滴妈呀。真的有年代感了。

V4.1 Flash 做出来了 3D 版，只不过我发现有个同样的问题，不管是 Qwen3.8-Max 还是 deepseek-v4.1-flash-expires-on-0910，摩托车的方向都特么是反着的。

【录屏】

第三人视角，有起伏弯道，路边有松树和岩石，还有对向来车。摩托过弯身体会倾斜到 47 度。

J 左拳，K 右拳，空格挥棍。攻击做了方向区分，左拳只能打左边的人，右拳只能打右边的人，不是无脑对着空气挥。命中有动作、火花、屏幕震动、合成音效。

高速撞车或者血量耗尽，骑手和摩托分离各自滑行翻滚，大概 3 秒后自动恢复。5 名 AI 车手会超车、贴身攻击，排名按真实行驶距离实时计算。

所有模型、赛道、贴图、音效全部代码生成，没有一个外部资源文件。

```
在新目录 deepseek/ds41-road-rash 中，用 Vite + Three.js 做一个 90 年代《暴力摩托》风格的 3D 竞速格斗游戏。第三人称追尾视角，有起伏弯道、路边景物、5 名 AI 车手和对向汽车，摩托过弯会明显倾斜。
WASD 或方向键驾驶，J 左拳、K 右拳、空格键挥棍。只能打中对应方向的近距离对手，命中有动作、扣血和音效；AI 会超车、靠近攻击。高速撞车或血量耗尽时，骑手与摩托分离并滑行，随后恢复比赛。
提供复古速度表、血条、真实排名、终点结算和重开。用代码生成模型，直接完成项目，实际启动检查驾驶、攻击和摔车，交付源码、运行地址和操作说明。
```
