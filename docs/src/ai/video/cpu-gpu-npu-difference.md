---
title: CPU、GPU、NPU 到底有什么区别？
---

AI 时代，你是不是也经常听到 CPU、GPU、NPU 这三个 PU？但完全不知道他们之间的区别，今天就用三分钟，彻底给你讲清楚。

拿 Codex 来说，这个程序运行在你电脑的 CPU 上，你发出去的每一个请求，则由云端数据中心的 GPU 完成推理。

那聪明的你应该已经注意到了，这两年新出的手机和电脑，参数表里都多了一个 NPU。比如说小米 18 Pro 就搭载了第六代骁龙 8 至尊版芯片，该芯片内部就集成了高通最新一代的硬件 NPU；再比如说微软和联想就联合规定，只有 NPU 算力达到 40 TOPS（每秒万亿次操作）以上的电脑，才能被称为真 AI PC。

恭喜看到这里的你，已经成功击败 30% 的学习者，给自己鼓个掌吧。**接下来我问你，CPU 和 GPU 的区别是什么？**

A，CPU 的主频更高；B，GPU 的核心更多；C，两种芯片各有各的场景。

说一下我的答案。

CPU 也就是中央处理器，核心数少，但每个核心都很强，擅长串行处理，擅长分支和复杂的条件判断，适合运行操作系统和各种应用程序，比如 Codex 这类 Agent 软件。它是整台电脑的指挥中心，负责控制其他处理器。

GPU 也就是图形处理器，拥有非常多的核心，可以并行处理，能高速完成矩阵计算和向量运算。它功耗大，但吞吐非常高，适合 3D 图形绘制、游戏渲染、机器学习的训练和大模型推理、视频剪辑、仿真模拟，这些需要一次性处理大量相似运算的并行计算。

按照英伟达 CUDA 编程指南的说法，CPU 把更多晶体管用在了缓存和流程控制上，GPU 则把更多晶体管用在了数据处理上。一台双路 32 核的服务器只能同时运行 64 个线程，而一块有 80 个 SM 的 GPU，能同时挂载 16 万个以上的活跃线程。SM 是流式多处理器，也就是 GPU 里的基本计算单元。

GPU 把 32 个线程编为一组，称其为 warp，同一个 warp 里的线程可以同时执行同一条指令。大模型里最吃计算的就是矩阵乘法，由于每个元素的计算互不依赖，所以正好可以交给 GPU。

恭喜看到这里的你，已经成功击败 50% 的学习者了。**接下来继续问你，GPU 已经能跑 AI 了，手机为什么还要单独加一块 NPU？**

A，NPU 的算力比 GPU 强；B，同样的计算，NPU 更省电；C，NPU 什么模型都能跑。聪明的你会选哪一个？

我的答案是 B。NPU，也就是神经网络处理器，专为神经网络中的矩阵运算而设计，极度适配智能手机或者边缘设备上的端侧 AI 推理。其典型应用场景包括人脸识别、语音识别、实时翻译以及计算机视觉检测，契合所有希望在终端设备而非数据中心运行 AI 的业务需求。

NPU 为什么省电？Google 2017 年发表的 TPU 论文里讲得很清楚，TPU 和手机里的 NPU 是同一类专用芯片。TPU 里有一块矩阵乘法单元，由 65536 个 8 位乘加单元组成，排成脉动阵列。数据在阵列里像工厂流水线一样一格一格往下传递，每个单元算完直接交给下一个单元，不用反复读写存储。TPU 的每瓦性能是同期 CPU 和 GPU 的 30 到 80 倍。

恭喜你，成功击败 70% 的学习者了。**继续问你，在自己的电脑上跑大模型，生成文字的速度主要看什么？**

A，NPU 的 TOPS；B，GPU 的核心数；C，内存带宽。聪明的你会选哪一个？

我的答案是 C。

大模型推理分两个阶段。Prefill 是预填充，模型一次性读完你的整段提示词，做的是大块的矩阵乘法，看的是算力。Decode 是解码，模型一个 token 一个 token 地往外生成，token 也就是词元。每生成一个 token，都要把全部权重从内存里读一遍，算力根本用不满，看的是内存带宽。

按 NVIDIA 技术博客的估算，一个 7B 参数的模型用 FP16 也就是 16 位浮点数存储，权重大约 14GB。生成速度的上限，大约等于内存带宽除以权重大小。

Apple 在 2025 年 11 月发布的 MLX 实测就是证据。M5 对比 M4，生成第一个 token 快了 3.3 到 4 倍，后面的生成只快了 1.19 到 1.27 倍。而 M5 的内存带宽从 M4 的 120 GB/s 提升到 153 GB/s，正好提升了 28%。

这也解释了为什么 Ollama 官方支持的硬件里没有 NPU，Apple 自家的 MLX 框架也只用 CPU 和 GPU。

TOPS 这个数字本身也有坑。NVIDIA 默认标的是稀疏算力，稠密算力只有一半；Intel 酷睿 Ultra 3 系列标的 180 TOPS，是 CPU、GPU、NPU 三块加在一起的结果，NPU 单独只有 50 TOPS。

算力决定第一个字多快出来，带宽决定后面的字多快出来。

最后再问你一个问题：“Agent 时代，算力都交给 GPU 了，CPU 是不是就不重要了？”

恰恰相反。Agent 等于 Model 加 Harness，Model 跑在 GPU 上，Harness 跑在 CPU 上。Claude Code 读取文件、执行 Bash 命令、调用工具、运行测试，这些都由 CPU 完成。

NVIDIA 在 2026 年 7 月发布的 Vera CPU 技术博客里专门讲了这件事，Agent 在两次 GPU 计算之间，要靠 CPU 完成工具调用、代码执行和沙箱运行。CPU 一慢，GPU 就只能干等；等得太久，KV Cache 也就是模型缓存在显存里的中间结果，还会被挤出显存，需要重新计算。佐治亚理工和 Intel 合作的一篇论文也测过，Web 搜索类 Agent 光是工具执行，就占了总延迟的 48% 到 55%。

恭喜你升到王者段位了，成功击败 99% 的学习者。

最后简单总结下。

CPU 负责指挥，GPU 负责大规模并行计算，NPU 负责在终端上省电地运行 AI，而大模型生成得快不快，主要看内存带宽。

另外，在本地部署大模型挑电脑的时候，先看内存容量和带宽，再看 TOPS；看 TOPS 的时候，一定要问清楚是什么精度、是不是稀疏算力。
