# 视频画面规范

二哥视频的画面怎么做，以本文件为准。Claude Code（`ergo-remotion-video` Skill）和 Codex 制作视频都读这一份，目录和命令另见 [WORKFLOW.md](WORKFLOW.md)。

参考实现是 `nine-prompting-techniques-for-better-llm` 第一章的 `Chapter1V2.tsx`，2026-10-04 用户认可。这一章的目录在本地，不入库；要看实现时让用户提供，或者直接读下面的共享组件。

## 一、画面靠动画，不靠文字

字幕已经承载完整的语言，画面只负责动画和视觉效果。每做一个画面，先问一句：这个意思能不能用界面操作、物体运动或图形变化表达？能，就不写字。

- 画面上只留短标签：术语名、产品名、模型型号、数值、坐标轴名。整句、问句、结论和台词都不上画面。
- 情绪不写骂人的字。“蠢”“Agent 不好用”这类台词改成漫画符号，比如锯齿气泡加 `#@!` 乱码、青筋符号。
- 概念用语义图形代替词语。参考实现里，示例画成文档，格式画成花括号，约束画成盾牌，格式错位画成裂开的花括号，逻辑断裂画成断开的节点链。

## 二、产品和模型写具体

- 讲到 Claude Code、Codex 这类工具的使用，直接画它的界面操作：输入框打字、回车、回复逐行出现、用 `/model` 切换模型。界面按产品风格绘制，不冒充截图，回复里的代码用语法配色色块表示，不写具体代码。
- 讲到“更强的模型”“更便宜的模型”，写当代具体型号（Anthropic：Fable 5.1、Opus 5.5、Sonnet 5.5；OpenAI：GPT-6 Astra、GPT-6 Luna），不用“顶级模型 $$$”这种泛称。
- 品牌图标只用 `shared/assets/brands/` 里核实过来源的官方素材。没有官方图标就用通用图标，不伪造品牌标志。

## 三、一章是一个连续画面

- 不再一段配一个场景、到点硬切。一章先定两到三个贯穿全章的主角，比如 Claude Code 窗口、质量曲线、模型标签。段落之间让主角移动、缩放、变色，承担新的含义。
- 前面提出的问题，在后面同一个对象上解决。参考实现里，第 3 段画出忽高忽低的质量折线，第 5 段同一张图上旧折线变灰，绿色上升线覆盖上来。
- 暂时用不上的主角退到背景（透明度 0.1 到 0.15）或淡出，主体区域不能只剩标题。
- 原稿配图照常整图展示（`FigureCard plain`），作为一段讲解的落点。
- 固定环节要灵活。关卡台阶这类每章重复的环节，和原稿配图抢时间时可以省掉，把时间让给配图；配图至少留 3 秒左右，太短看不清。

## 四、去掉框，用明暗分主次

- 自制图示默认不套卡片和边框。图标、大字、曲线直接放在背景上，尺寸放大，一个画面只突出一个主角。
- 产品窗口、代码块这类本身就是容器的对象，用深色实体加投影表现，不用描边框。
- 不做“虚线大框里放两张卡片，中间一个加号”这种结构，也不做卡片套卡片。
- 主次靠大小、明暗、背景点阵和跟随主角移动的焦点柔光（`Spotlight`）区分。

## 五、动效

- 位置、缩放、透明度都按关键帧插值，缓入缓出。元素在术语起音前 4 到 6 帧开始入场，弹出时带一点回弹。
- 折线和数据点同步出现，按点逐段画线，不按路径总长度画，否则线头和点会对不上。
- 元素稳定后不循环脉动。表示“正在工作”的思考标记可以持续旋转。

## 六、共享组件

从项目 `remotion/src/` 引入，路径前缀 `../../../shared/remotion/components/`。

|组件|文件|用途|
|---|---|---|
|`track`、`life`|`Stage.tsx`|按关键帧插值；按入场和淡出帧算透明度|
|`Actor`|`Stage.tsx`|以中心点定位元素，位置、缩放、透明度由调用方按帧计算|
|`Spotlight`|`Stage.tsx`|背景点阵加跟随焦点的柔光|
|`ClaudeCodeWindow`、`CodexWindow`|`ProductWindows.tsx`|产品界面示意：打字、思考标记、回复逐行出现、`/model` 菜单|

新章节从 [examples/Stage.example.tsx](remotion/examples/Stage.example.tsx) 复制起步。旧项目保留原来的写法，不批量改版。

## 七、交付前自检

1. 静音看画面，能不能看懂这一段在讲什么？
2. 遮住字幕，画面上有没有整句话或台词？
3. 相邻两段之间，有没有至少一个元素延续下来？
4. 有没有卡片套卡片、虚线框套框？
5. 提到的产品画了界面吗？提到的模型写了具体型号吗？
