看到 Kimi 直接基于 Pi 设计了 自己的 Harness，这一定是一个正确的决定
1） Weak loop Strong tool，loop 是 Harness 的核心，但是却并没有那么重要，因为 loop 的设计不会有任何的差异化，无非就是上下文的拼接和考虑各种格式的端点，而使用 Pi 完美的解决了这部分的工作量
2）无懈可击的定制化，除了以上两个部分，Pi 的任何东西都可以极其方便的定制化，包括但不限于 system prompt、tool schema、TUI 和强大的 extentions 系统。这些属于厂商需要和自家 LLM 适配的部分，Pi 允许你优雅的定制化，这里减少了非常多的代码量

其实可以归纳为一句话
"用 Pi 自研 Harness 和你自己从头自研一个 Harness 没有任何区别，但减少了极多的工作量，还能白嫖了社区维护"
