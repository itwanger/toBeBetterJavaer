pnpm run clean

pnpm run build
pnpm dsh web

## 03、锦鲤食堂

先放效果。

【录屏】

这次有点问题了，鱼没有来吃鱼食，鱼食就消失了。😄

但水和鱼的动态是没问题。

GPT-6 Astra作为裁判打了 6.5 分。鱼、水草、鹅卵石、荷叶和水光都有，鱼体会弯曲，投食后确实会聚拢进食；拨水、暂停、重置也有效。

提示词：

```
在新目录 ds41-koi-pond 中，做一个可交互的日式锦鲤池网页，技术自选。俯视清澈池水，能看到鹅卵石、水草、水面波纹和阳光折射的光斑；至少 8 条红白、金色、黑白锦鲤自然游动，身体弯曲带动尾巴摆动。
点击水面投放鱼食并产生涟漪，附近的鱼会转向、加速聚拢，吃完后散开；拖动鼠标能拨动水面。提供投食提示、暂停和重置，画面安静、精致、适合全屏展示。
用代码绘制场景和鱼，不依赖外部图片或视频。直接完成可运行项目，实际验证连续投食和重置，交付源码与运行地址。
```
