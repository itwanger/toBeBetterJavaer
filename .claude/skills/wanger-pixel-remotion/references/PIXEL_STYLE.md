# 像素风 · 二哥的五分钟横版科普

一张场景先回答三个问题：谁在做事，什么东西变了，哪件东西得留在原地才能看出差别。城市、平台、题牌适合建立地点；开始读数字、看编码或做对照时，镜头可以退到干净的讲解底。正式章节从[已认可的 Tokenizer 第一章](APPROVED_PIXEL_CH1.md)取舞台、人物、旗面、按钮和提示音。参考片的具体帧见[逐帧拆解](PIXEL_REFERENCE.md)。

人物表情、同杆逐关跳旗、同帧更新原图和读数，以及整片声画拼接均按[认可定稿](APPROVED_PIXEL_FINAL.md)执行。前三章样例保留各轮的制作细节。

## 从口播到场景

1. **把稿里的名词摆上台。** 在本期 `OUTLINE.md` 记录画风、每章的问题、输入对象、变化前后、需要延续的身份、原稿配图以及语音锚点。角色可以拿、送、等待或见证；每个知识对象只占一个身份。五分钟允许回到同一个工作台多次，第二次从观众已理解的状态开始。
2. **选一个能讲清关系的空间。** 要交代旅程或把物件从一站送往下一站，用横版平台；要比较切法或展示编号，用浅色讲解底；要引用用量、原文或实测，用原图、原网页或真实录屏，保留原始比例和文字。术语起音时，主要对象已经能认出来。做章节地图时，节点对应稿里真的换了的问题；“击败 30%／50%…”只在稿子提到时更新，停留后让出空间。
3. **给动词写接触帧。** 先写旧状态，再写触发点、发生变化的对象与新状态，然后接下一句。用对象守恒验收，例如 `i n g → in g → ing`：左侧短了，右侧学到的新条目增加了，已有条目仍在。对“等待”，留住处理中的另一端；对“比较”，两边共用输入、坐标与尺度。可以让角色走近、停下、回应，把最强动作留给本句正在解释的对象。
4. **将草图时钟换成口播时钟。** 风格试镜可以用试排帧；正式章从本期对齐文件取帧，以一句里真正触发动作的词定位接触、揭晓与结果停留。接触声对齐碰到的那一帧，完成声对齐结果落定；已有旁白的词头和尾音要能听清。连续步骤共用一条轨道。同一空间内切局部或回到全貌时保留能认出来的对象；只有切换空间时才考虑短菱格遮罩，字幕层保持稳定。
5. **先按帧查，再连播。** 截触发前一帧、触发帧、运动中段、落定和下一句开头。遮住字幕能否看出谁变了？输入是否重复了一帧，新对象是否提前出现，角色脚底是否漂移？把最密一帧缩到 390px 宽，查中文、Token ID、连线和字幕是否仍可辨。正式章还要带真实音轨按正常速度在 Studio 连播，按原工作流逐章审片。

## 随口播移动主体

从当下要讲的对象开始排版。只有问题，就让问题在主体区居中，占足阅读空间。讲到候选词，问题再上移，词签入场。新数据属于已有对象时，让对应对象就地变宽或移动，整组随之重新居中。未来才需要的列、空框、概率底槽都等到各自的触发词再出现。比较过程中，要保留观众正在追踪的词签、颜色、顺序和数值尺度。

《DeepSeek API 中的 Temperature 有什么用？》第二关可以逐帧对照这个过程。F168 只有居中的提问；F436 三张横排词签各自带着刚念到的分数。F553 开始讲概率，词签先沿纵向错开，再向左收拢，避免三张签同时横移时互相遮挡。F610 时三行已对齐，右侧概率条展开。讲到零温，计算区域退场，词签回到中央，最高分的那张抬起。换题时用当期口播确定触发点。[第二关动效摘录（GIF）](sampling-layout.gif)

落地时让同一对象连续插值位置、尺寸，保留它的身份。仅把未来内容设为透明，仍可能让布局提前空出一列。审片时分别停在触发前、移动中和落定后：触发前是否由当前对象用足主体区，移动中能否一直认出同一对象，落定后新数据是否与对应对象对齐。按正常速度回放确认阅读时间。

**连续点名。** 在状态栏下沿与字幕上沿之间排好当前对象：只讲一个插件时，大字和图形一起居中；第二个到来，第一张缩小移向一侧。第三个出现可把第一排上移、第三张在下方居中；第四个到来，再把第三张移到左下，组成两行两列。口播没提到的格子不画。讲新的选题时，把原有四张一起缩成一组，让出空间。连看单项、让位中段、最密排布三帧，再缩到手机宽度看字。[插件登场的实际成帧](plugin-reflow.jpg)

## 换景与声音同帧

按两个镜头的关系选动作。切到相邻工作区时，两面沿同一方向横向交接。前一组数据引出下一组对象时，上一组上移，下一组从下方进入。打开作品时，让新视窗从小到大展开，保持文字不透明。三种动作复用小超风格的 [MotionPlane 与花叔转场样例](../../ergo-remotion-video/references/APPROVED_MOTION_TRANSITIONS.md)。状态栏和字幕留在原位，提示音跟随交接动作。

从讲解进入游戏跑道、跑道接下一章时，可保留像素菱格。遮罩放在主体之上、字幕和 HUD 之下。遮满时切新景并播放短扫音。跨章时上一章画收拢半程，下一章画揭开半程，在交界放一次声。同一图窗里的线条生长、圈选和卡片让位由对象自身完成。

重配、换素材或合章后，从实配时间重算事件再混音。查切点前、中、后帧，用 Studio 的有声合成以 1 倍速连过边界；核对实际播放的音轨含提示音。若不清楚，检查旁白下的局部响度。

## 美术和 Remotion 落地

- [PixelWorld.tsx](../assets/PixelWorld.tsx) 是实际跑过的 1920×1080 舞台。复制到项目 `remotion/src/`，`mode="platform"` 给天空、地面与可选任务牌，`mode="diagram"` 给机制和对照保留大块浅底。SVG 子节点画机制；`foreground` 可放透明人物。项目里已有字幕层时只保留一份文字。在正式像素风章节中把右上状态栏放在世界与镜头之上：三颗像素红心、金币计数、作者“沉默王二”。`coins` 传截至当前事件已完成的成就数，读同一期的累计进度，切镜不清零。
- 舞台色板为本系列选色。米色底、深墨色描边，青绿给稳定结构，金色给当前操作，橙色给触发件。状态同时由形状、位置、符号或词条表达。人物用原创二哥或本期自己的角色，姿势有清晰脚底基线；平台、方块和机械件使用少量实色、硬边和统一网格。商业游戏和参考作者的角色、音乐及截图不作新片素材。
- 示例精灵与机械坐标吸附到 4px 设计网格，用整数倍或最近邻显示。中文、数字、截图和字幕按输出分辨率排版。机制与证据镜头用浅底。人物可直接置于留白，提问时朝图伸手、读细节时退场、换到工位时走近。姿势跟口播里的动作走；单纯站立无需底座。台阶、路面和道具只在有实际空间用途时绘制。`ground` 控制通栏地面，章节按镜头选择。口播字幕使用底部居中的窄黑底文字牌，宽度随句长变化，可高亮术语；没有字幕内容时隐藏整块。示例字号 48px，可按句宽调整断句；常规对象标签从约 40–48px 起试。所有数值是这套 1080p 舞台的起点，需看实际缩图；长句优先换字幕块。
- 状态只读 `useCurrentFrame()` 与本期时间轴。角色按动作切整身姿势；脚步用离散帧，物件沿因果路径移动。触发前后用同一个事件帧驱动旧物消失、新物出现与词表更新。进入下一章需要延续的位置写入下一镜初态，帧跳转、拖动与线性播放应得到同一结果。
- 机制取景采用自己的像素世界；讲实际 API 用量、具体版本的词表或模型测量时，回到对应的一手原图。数据角标要能追到稿件或来源。音效从现有自有/共享提示音中选，完整音效计划和素材来源写入本期项目。

## 手机折线动效

口播讲一条曲线如何变化时，沿用《DeepSeek Harness 四个插件》开场的处理。先用像素视窗交代原图，再把空间给绘图区。本例在 1920 像素宽的画面里将图窗展开到 1560 像素，给日期、刻度、字幕和终点读数都留出位置。

用原图坐标画动画层，让加粗的蓝线跟随金色亮点向前延伸。每到一个原图标出的节点，圆环向外扩一下，节点下方出现高对比度的中文读数，保留到下一个节点。这样观众中途看回画面，也能认出刚走过的数值。实线与虚线沿用原图，到达终点时对齐口播报数，停稳后再换图。没有中间观测点的连续曲线只沿线移动，在原图给出数值的位置标数。

将实际成帧缩到约 390 像素宽，以正常速度连看整段。检查第一眼能否找到移动的亮点、节点读数能否一眼读清、镜头推近后终点是否完整。若仍需盯着小点看，优先放大绘图区、加粗已走过的线，再调整亮点和读数牌的大小。[已认可的手机尺寸动图](approved-mobile-chart.webp) · [对应组件](../../../../docs/src/ai/script/deepseek-harness-four-plugins/remotion/src/ChartTrace.tsx)

## 含图片的镜头

拍插件操作时按[归藏设计的实测镜头](PLUGIN_WALKTHROUGH.md)衔接入口、输入、结果和验证。

从多栏总览切到单栏特写时，准备独立裁图并对齐实际可见内容。示例输入和接收方同名时，以文字工位与官方品牌标识区分职责。[第一章最终取景与工位](APPROVED_PIXEL_FINAL.md#截图切换与模型工位)

**分层取景。** 讲控件位置时，以完整的真实界面托底，从原位放大整个控件；放大镜和框线四边都留在视窗内。切到 PDF 或白底文档阅读时，用原页铺满同一视窗，把配图、公式和标注放在独立图层。让观众正在看的对象从原位置移动，等旁边的旧内容退场，再在腾出的地方引入新内容。按手机宽度检查切入、移动中段和停稳帧，确认纸面四边颜色一致，没有残留的侧栏、半截邻栏或互相遮住的文字。

先判断观众要辨认的对象。仓库、原文或多栏截图先给整体，以原图坐标标出目标段落、数据或区域。随着触发词在同一素材里推近、平移或滚动，焦点停稳后再框选。检查聚焦后的源区域四边，保住完整一组数据以及识别它所需的上下文；能整图读清时保留全貌。像素风正文中，独立展示的截图、原稿插图和 GIF 默认放进分词器样例的像素视窗（静态图用 `PixelImageWindow`，动图沿用同款外框）。先在窗内等比展示全貌，再按口播推近或框选。连续读同一张图时，外窗位置和尺寸固定，图片和高亮共用原图坐标。如果素材本身已经带有完整的播放器或窗口外框，沿用它自己的外框。生活插图可以直接成为场景内的物件，如电脑屏幕里的配图。Tokenizer 开场的原图标题右侧有留白，将提问人物嵌进窗口，用回收的侧边空间放大整图；推近正文之前隐去人物。

Tokenizer 第一章把关键词“分词器 Tokenizer”置于左上，与右上状态栏共用安全边距。开场从同一官方网页和实测页面以四倍像素密度重拍，外窗宽度跨聚焦镜头固定，只移动里面的原图。讲切分时先标单条字带的边界，切刀落下才分开。进入跑道使用短菱格遮罩，在遮满画面、切换世界的那一帧加轻扫音。画面尺寸、音效响度与此处的关键词属于本期设置。

人物用来提问、操作或回应。决定谁出场时，看该切口是谁的动作：原片有左侧品牌与右侧仓库的镜头，也有旁边角色伸手、图里机器人自己承担讲解的镜头。读密集图片时，可以把画面交给图片；角色静止时也不需要专门给脚画一条线。[参考片图片与人物取景](PIXEL_REFERENCE.md#图片如何进入镜头)

## 连续讲解与左右分窗

主窗口的可见外沿分别对齐左上主题牌和右上状态栏，两侧留白对称。三列等距，图文分栏允许异宽。按成帧检查描边、图片比例、框内内容与人物落点。[认可版尺寸和对照](APPROVED_PIXEL_CH2_CH3.md#顶部状态栏与主窗口共用外边线)

同一个输入从文字变成编号、从编号到结果时，固定工作台的方向和词块的顺序，让观众能跟着一块走完全程。原稿动图的节奏与配音不同时，先找出动图里能辨认的动作，再把这些时刻对到本章的触发词，中间按帧推进。若讲的是带人物的多栏图，左窗固定整图，细框只圈当前数据；右窗从同一文件、同一组原图坐标等比放大。

横排的输入、处理、结果框也可以作为人物的落脚点。把落地与对应框的词条点亮对齐；读表时让人物停稳。排版从字幕上缘和状态栏之间的可用高度出发，把额外高度给字格、行距或结果行。按最密状态和起跳最高点检查文字、人物和字幕。[第二、三章的成帧、原图与调用方法](APPROVED_PIXEL_CH2_CH3.md)

## Tokenizer 的第一轮试镜

[分镜和复核记录](../../../../docs/src/ai/script/what-is-tokenizer/OUTLINE.md)提供五章和原图的落点。[BPE 动作试镜](../../../../docs/src/ai/script/what-is-tokenizer/preview/bpe-merge.gif)取自 `i + n`、`in + g` 的教学例子；压机是训练合并的比喻，现学词表与使用已训练词表处理新输入需要分镜讲。试镜采用本地已有二哥精灵；正式章认可版成帧见[第一章样例](APPROVED_PIXEL_CH1.md)。将这套风格用于其它主题时，沿用空间连续性和对象动作，按新题材重新选择道具。

**先登阶，再跳旗。** 旗杆左边留出助跑段，接几级有明确踏面的砖阶。人物逐级抬脚，在最高一级站稳，再从阶沿起跳。用同一套踏面坐标画楼梯和算脚底轨迹。最高关复查头顶与状态栏的距离。起跳短音跟离阶帧，金币跟落座帧，旗面承重后人与旗一起下降。[登阶到落座动效](stair-to-flag.webp)

Tokenizer 样例的旗布采用约两个人物宽度，按缩小后的旗面重算坐姿支撑点；过关画面恢复早期试镜的深色通栏字幕。Tokenizer 第一章以“30%”起音为落座帧。旗布横向展开，让坐姿角色的臀部与布面上缘接触，双腿垂在旗前。留一拍坐稳，旗面承重略微下陷，再与角色一同下降。两者共用同一个支撑点坐标，落座与金币提示同帧。旗杆在侧面，仅用来悬挂旗帜。旗布写“30 分”等关卡得分，口播和字幕保留学习者百分比。后续段位沿用同一根旗杆和同一条跑道，百分比越高，旗面和起跳弧线越高。[项目实现](../../../../docs/src/ai/script/what-is-tokenizer/remotion/src/FlagCourse.tsx)

**独立片尾。** 先看当前句在说什么。学习提问、点赞关注和二哥告别有自己的镜头。从总结或问句切入新场景，让二哥面向观众，提问时留出回应的一拍，告别时用手势收尾。成绩旗只配本段明确说到的过关成绩。

下一期可试用[成长片尾组件](../assets/PowerUpOutro.tsx)。暖色天空与远山沿用 PixelWorld，关闭地面。小二哥顶起问号块，接住带书页记号的蘑菇，完成第一次长大。点赞和关注各按下一次，像素光从对应按钮飞回角色，再升一级。“我是二哥”时保留最大身形，报名字并挥手。把问句起音当作第 0 帧，按本期实际词头传 unlock、like、follow、name、bye；按键声落在按钮压下帧，收取声落在蘑菇碰到人物的一帧。依赖同目录的 PixelWorld、LikeFollowTiles 及 pixel-actor 人物图。在 Studio 单独注册 NextOutroPreview 可试听这版试镜。

**点赞关注。** 口播出现这两个词时，由各自的起音驱动两张像素按钮：先让带拇指的“点赞”入场，再并排出现带红心的“关注”。手形指针依次点按，两张按钮一同留到人物回应，然后给下一步让出空间。镜头内为动画反馈。本期两次按下分别配原创短脉冲单音和上行双音，在提示音混音中检查按钮按下的帧与旁白响度。[原片抽帧](PIXEL_REFERENCE.md#点赞与关注)
