# 首版选镜与共用自审

先按[统一入口](../SKILL.md#导演规则分流)选择本期导演规则，再从[认可镜头与素材索引](SHOT_LIBRARY.md)按当前画面任务取镜头。本文件只维护两类共用的首版落地与观察方法；导演规则决定解释过程或证据组织，认可样片提供具体拍法。

**首段试镜**选本期最容易画成文字板的一句。沿一次连续预览关注主体占比、动态让位及对象边界；无需再为同一问题额外导出静态帧。左上主题牌承担章节名，物件承载短名和必要读数，口播由字幕承接。删掉一行重复文字后，把腾出的高度还给主体。最后开声看一次动作、字幕和音效能否在同一拍对上。

Fable 第一章按[FABLE_CH1_LIBRARY.md](FABLE_CH1_LIBRARY.md)取最终认可素材，不以旧版本对照图作为新项目制作基准。

**按原稿选主角。** 先摊开这章已有的插图、录屏和原文，给每段配音找对应物件。清楚的静态像素插图直接用：先按成片比例看全貌。只需认位置时可在原图点亮对象。原文章插画整体取景，读细节时跟随同一对象推近；需要动态机制则另建场景承接，不默认拆分原图。[看第三章如何从总览切到算力台](FABLE_CH3_LIBRARY.md)。GIF 在实际取景下看不清关键动作时，才为该镜找高清原片或重录。讲抽象机制时，优先接回稿里已经出现的实例；额外举例若会让观众误以为是本期实测，改用原稿里的对象。章节名只在左上主题牌出现一次。素材自带题签时保留原题签，不另叠同义大标题。终端画面只排观众会用到的命令、问题、模型和结果。真实采集、模拟生成与完成后回看等来源说明只写在取材记录里，不自动叠加到片中。

**从暖底开始搭场景。** 自绘讲解、工坊和科研镜头优先沿用 `PixelWorld.tsx` 导出的 `pixelColors`。用 `cream`（#fff2d4）铺大面，浅沙色分地面与远景，`ink`（#25263b）画轮廓、招牌和浅底正文，`teal` 标读数，`gold` 或 `orange` 标动作。显示器、芯片、黑洞等深色集中在物体内部。网格只用在确实需要展示坐标或寻路的局部。原始视频、截图和论文保留原色。取一帧实际渲染的工作全景与[插件集市认可画面](approved-harness-ch1/market.webp)并排，先看人物四周和屏幕边缘是否仍是同一暖底，再读数字和字幕。[共享色板](../assets/PixelWorld.tsx)

在项目 `OUTLINE.md` 现有分镜中，给难拍的一句补上「哪个词触发动作、观众此刻看谁、要从哪个认可镜头借做法」。按这句话去取材和试镜。先确定谁在说这句口播。二哥向观众提问、思考、指认或过关时，从现有[人物姿势](../assets/pixel-actor/)与[ReactionActor](../assets/ReactionActor.tsx)取讲解者；镜头进入任务演示时再引入承担操作的角色。遮住文字也应能分清二哥和 Agent。

天空与马路同框时，沿用 [PixelWorld](../assets/PixelWorld.tsx) 的全宽地下字幕带（`captionStyle="band"`），路面下沿接住字幕背景。转进无马路的讲解空间时换用字幕牌（`plaque`）。只核对本次改动的换景接缝，场景与字幕按同一处切点切换。

读双轴评测图或在实机录像上比较成绩，见[第四章的取景和叠分动效](FABLE_CH4_LIBRARY.md)。验片时看数字出现前后，底层动作是否继续向前。

**给每一处屏幕文字一个用途。** 看已带完整字幕的成帧：如果去掉标题或标签，观众还能从对象、动作和字幕得到同一条信息，就删掉这行字。空文件夹可以点开给人看；软件工具能用有辨识度的标志，离线环境可用带锁的终端。分派任务时让一部分角色跟着同一张单据走，留住未调动的队伍。结果先让对象变成完成态，再把需要读准的数值放到物件上。并列能力、类别和用途用图标配短名，便于观众把每个图形和口播中的词一一对应。专名、比较指标、单位和帮助读原图的局部标注也应保留。按实际播放比例查看最密的镜头，先遮住字幕看动作，再打开字幕检查有无重复。

首版试镜时，给所选镜头保留足以判断上述问题的连续短段，或按真实口播取初态、中段、落定三帧。在项目的 `preview/` 内按实际画布比例看一次，有缺口就回到源素材、布局或角色动作修正。这一步由制作者完成，随后进入已有的全章有声审片流程。
