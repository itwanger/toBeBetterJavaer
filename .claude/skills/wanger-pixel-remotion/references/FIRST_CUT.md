# 首版选镜与自审

## 拿到下一期口播，先从两期定稿里选镜

| 这句话希望观众看到什么 | 首版取哪种拍法 |
| --- | --- |
| 知道主角是谁、各自做什么 | 二哥负责提问、指认、过关。多个工具出场用暖底摊位与图标短名，协作则让工件在角色之间交接。[Harness 集市](HARNESS_CH1_LIBRARY.md) · [Fable 工坊](FABLE_CH1_LIBRARY.md) |
| 看懂某一次操作 | 先给工作台全景，保住按钮和控件两端；在原位放大，沿同一输入定位到结果。截图只套一层轻量 Mac 窗，原图窄时按原宽收窗。背景持续运行，说明贴在所指对象旁。[工作台与跨栏](HARNESS_CH2_LIBRARY.md) · [原片上叠读数](FABLE_CH4_LIBRARY.md) |
| 了解一个机制或看出策略变了 | 清楚的静态插图直接用。指认一个部件时让部件动；讲某一项机制时转到独立场景。同一难题可以用失败、换路、成功三步讲清。落水时水花、提示音、扣心同步，顶砖得到的心飞回同一格。用本期真实任务作为终端问题。[第三章机关桥与终端](FABLE_CH3_LIBRARY.md) |
| 读一组先后出现的数字或对象 | 先让当前对象用足主体区。下一项的词头到了，旧对象移动或缩小给新项让位。手机上读折线时先走两轴，再让亮点沿真实数据移动。[卡片重排](FABLE_CH1_LIBRARY.md) · [读轴与追线](FABLE_CH4_LIBRARY.md) |
| 相信一项跑分、速度、费用或配额 | 先有真实题目、可复现的检查或同题对跑，后叠准确数值。把汇总范围和计价单位放在需要读数的地方。配额可直接画成相应数量的券。[第五章六个有声样例与可安装组件](FABLE_CH5_LIBRARY.md) |

**首段试镜**选本期最容易画成文字板的一句。播放到下一元素入场前，看主体是否已经用足四边；播放到动作中段，看新增图层是否挡控件、字幕或角色；停在结果帧，以 390 px 宽读一次必要的小字。左上主题牌承担章节名，物件承载短名和必要读数，口播由字幕承接。删掉一行重复文字后，把腾出的高度还给主体。最后开声看一次动作、字幕和音效能否在同一拍对上。

《Claude Fable 5.2》第一章本轮调整前后沿用同一段配音。图中上下两行取自两版 MP4 的相同帧，可以直接看出构图上的差异。[上方为调整前，下方为定稿](approved-fable-ch1/comparison.webp)

**按原稿选主角。** 先摊开这章已有的插图、录屏和原文，给每段配音找对应物件。清楚的静态像素插图直接用：先在手机宽度看全貌。只需认位置时可在原图点亮对象。进入单项机制时，抬起当前格、淡出邻格，让新场景独立承担后续动作；读真实细节时则跟随同一对象推近。[看第三章如何从总览切到算力台](FABLE_CH3_LIBRARY.md)。GIF 缩到手机仍看不清关键动作时，才为该镜找高清原片或重录。讲抽象机制时，优先接回稿里已经出现的实例；额外举例若会让观众误以为是本期实测，改用原稿里的对象。章节名只在左上主题牌出现一次。素材自带题签时保留原题签，不另叠同义大标题。终端画面只排观众会用到的命令、问题、模型和结果。「演示」「示例」等制作说明记在取材记录里。

**从暖底开始搭场景。** 自绘讲解、工坊和科研镜头优先沿用 `PixelWorld.tsx` 导出的 `pixelColors`。用 `cream`（#fff2d4）铺大面，浅沙色分地面与远景，`ink`（#25263b）画轮廓、招牌和浅底正文，`teal` 标读数，`gold` 或 `orange` 标动作。显示器、芯片、黑洞等深色集中在物体内部。网格只用在确实需要展示坐标或寻路的局部。原始视频、截图和论文保留原色。取一帧实际渲染的工作全景与[插件集市认可画面](approved-harness-ch1/market.webp)并排，先看人物四周和屏幕边缘是否仍是同一暖底，再读数字和字幕。[共享色板](../assets/PixelWorld.tsx)

在项目 `OUTLINE.md` 现有分镜中，给难拍的一句补上「哪个词触发动作、观众此刻看谁、要从哪个认可镜头借做法」。按这句话去取材和试镜。先确定谁在说这句口播。二哥向观众提问、思考、指认或过关时，从现有[人物姿势](../assets/pixel-actor/)与[ReactionActor](../assets/ReactionActor.tsx)取讲解者；镜头进入任务演示时再引入承担操作的角色。遮住文字也应能分清二哥和 Agent。

天空与马路同框时，沿用 [PixelWorld](../assets/PixelWorld.tsx) 的全宽地下字幕带（`captionStyle="band"`），路面下沿接住字幕背景。转进无马路的讲解空间时换用字幕牌（`plaque`）。逐帧看换景前、中、后，场景与字幕按同一处切点切换。

读双轴评测图或在实机录像上比较成绩，见[第四章的手机取景和叠分动效](FABLE_CH4_LIBRARY.md)。验片时看数字出现前后，底层动作是否继续向前。

**给每一处屏幕文字一个用途。** 看已带完整字幕的成帧：如果去掉标题或标签，观众还能从对象、动作和字幕得到同一条信息，就删掉这行字。空文件夹可以点开给人看；软件工具能用有辨识度的标志，离线环境可用带锁的终端。分派任务时让一部分角色跟着同一张单据走，留住未调动的队伍。结果先让对象变成完成态，再把需要读准的数值放到物件上。并列能力、类别和用途用图标配短名，便于观众把每个图形和口播中的词一一对应。专名、比较指标、单位和帮助读原图的局部标注也应保留。把最密的镜头缩到手机宽度，先遮住字幕看动作，再打开字幕检查有无重复。

**复用工坊角色。** 安装像素素材包后，从 `remotion/src/WorkshopBot.tsx` 导入 `WorkshopBot`，放在 SVG 舞台内。传入 `job`（`code`、`test` 或 `review`）、局部帧 `f`、脚底坐标 `x` 和 `y`；`scale` 调整尺寸，`walk` 启用步态，移动路线由调用者决定。三种角色的工具和面罩不同。工位可以按新稿重画。[可安装角色](../assets/WorkshopBot.tsx) · [本期工位、镜头与传送带接法](../../../../docs/src/ai/script/claude-fable-5-2/remotion/src/AgentWorkshop.tsx)

**硬件从整机定位到部件。** 选镜时可直接看[第二章定稿的板边、标注与任务交接](FABLE_CH2_LIBRARY.md)。 先用能辨认整机的原图，再切到对应部件的剖面。进声孔、麦克风等容易误认的部件用短名和指引线，尺寸括号贴着实际量测的两端。总览中保留外轮廓、描边和投影；背景原片与示意图层各自取景。在最大放大帧同时检查四边、HUD、字幕和引线。

首版试镜时，给所选镜头保留足以判断上述问题的连续短段，或按真实口播取初态、中段、落定三帧。在项目的 `preview/` 内以 390 px 宽看一次，有缺口就回到源素材、布局或角色动作修正。这一步由制作者完成，随后进入已有的全章有声审片流程。
