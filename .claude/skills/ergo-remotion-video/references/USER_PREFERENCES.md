# 用户偏好

本文件维护内容与视觉偏好；目录和命令以 [共享工作流](../../../../docs/src/ai/script/shared/WORKFLOW.md) 为准。

## 项目与验收

- 共用配置、工具、组件放 `script/shared`；每条视频的原文、稿子、图片、音频、动画、试听、时间轴和成片集中在自己的主题目录。
- 项目 `project.json` 保存实际采用的配置。修改共享默认值不会改变旧项目；用户明确要求同步时才更新旧项目。
- 用户逐章验收，回复「继续」推进下一章；明确要求「渲染 / 出片」才导出 MP4。已授权就继续，不重复索要许可。
- 章节数与实际时长由内容决定；配音分段以自然意群为准，不固定段数。

## 内容和朗读

- 文章转视频默认从文末公众号推广尾段的起点删至文件末尾，该句及后续全部图片一起删除。项目 `article.md`、`script.md`、`beats.json`、分镜和素材清单同步清理，不保留排除条目或完整尾段副本。原始源文章不自动改写。正文资料领取（288 道 / 222）和视频点赞关注结尾继续保留，除非用户另行要求。不要每次重新询问这条已确定的偏好。

- 用户确认的稿子按原文读，不自动加情绪、反问、语气词，也不批量改写数字。
- `text` 保留字幕原文；`ttsText` 表达用户明确指定的读法。
- 「需要的可以来个222」中的 `222` 读「二二二」；「288 道」读「二百八十八道」，字幕仍保留数字。
- 修改读法只重做受影响的配音单元，再更新处理音频和时间轴。
- 配音保持完整句子或自然意群，字幕与动画在同一段音频内独立切换；具体拆分与修复原则见主 Skill。
- 音色与倍率以当前项目配置及用户最新要求为准，不能把历史 1.10、1.15 等写成永远最佳值。
- 「3 分钟」可按稿子保留，实际时长以生成音频为准。

## 视觉与人物

- 视觉表达优先于长段文字堆屏，原稿大图和语义动画互补。信息密度来自对象、关系和步骤，不能用几个字母方块取代完整技术图。金句、术语可用大字卡片；面试对话优先通过角色和语义动画表达，避免和底部字幕整句重复。
- 正文复用完整章节胶囊导航 `ChapterStrip`：左侧主题品牌，右侧全部章节，当前章黑底白字，已过章节灰色。章节数由内容决定。底部保留单行字幕；面试开头的特殊版式不改变正文样式。
- 平台播放器已提供播放进度，视频画面不额外绘制章节或整片播放进度条，正文、开场和结尾均适用。复用旧项目场景时移除相应的进度条元素；章节导航和内容本身需要的训练进度、任务状态等示意照常保留。
- 白底、黑边、圆角约 32px、轻偏移阴影统一卡片风格。图形、短标题和说明共同承担信息，字号服从版面，不遮挡导航或字幕。
- 连续场景持续挂载；元素一次入场后稳定显示，不循环脉动，不逐句重播入场。
- 保留正文配图逐张映射到场景与 beat 范围，原样使用并检查实际出现在预览中；只下载或登记来源不算完成。未采用时记录原因，不因“动画为主”直接略过。原图上的说明文字完整保留。
- 配图在中央大卡片中等比完整显示，优先保证可读。1920×1080 下可从约 1210–1280×680–720 的区域起步，给顶部导航、底部字幕留空间；宽高由图片比例和信息密度决定。图片不加无关扫光、旋转或重新生成人物。
- 同一图片可持续承接多个相邻 beat，仅切换字幕；需要讲局部时添加克制的框选、指示或高亮，不重新挂载原图。原理动画与整图展示可分别承担演示和归纳，不互相替代。
- 问题导览卡默认用短标题、简短说明与语义 SVG 图标；缓存、书架、显存容量等示意保留逐步读取、追加、匹配、增长或压缩动作。不要全部简化为文字卡。
- 默认人物位于 `script/shared/assets/ergo-avatar.jpg`，项目副本在 `assets/images/ergo-avatar.jpg`。当前为用户提供的黑框眼镜、黄衬衫、黑领带形象。
- 已有学习者、老师或讲解者的科普示意，优先复用二哥与豆包的角色头像，替换通用线条小人：二哥对应学习者，豆包对应老师或讲解者。保持角色标签与稿子含义一致，不将示意角色写成真实人物或产品的事实陈述；用户指定角色优先。普通科普无需增加面试情节，也不批量替换旧视频或修改原稿配图内的人物。
- 角色素材复用 `shared/assets/interview/` 中的 `ergo-facing-left.png`、`doubao-facing-right.png`，复制与来源记录按 [共享工作流](../../../../docs/src/ai/script/shared/WORKFLOW.md#面试开场素材)。根据位置让人物面向互动对象或画面中心；这些无文字头像可用显示层镜像调整朝向。按视觉大小统一容器，保留脸、头发和识别特征，不遮挡文字、字幕或语义标记；沿用当前场景版式，不因复用头像而套用面试布局。
- 圆形头像使用 `objectFit: cover`、`objectPosition: center top`，以脸和头发完整为准；完整人物图使用 `contain`。
- 二哥自介按稿子，不额外添加 `HOST` 英文标签。
- 常规自介和结尾优先用圆形头像、红色细边及黑色姓名胶囊，旁侧放主题大字、结论与少量标签；用户另有指定时优先。
- 机械/物理示意使用 SVG 或 div；横向运动图标方向与运动一致。

带面试对话的稿子按 [面试头像开场](INTERVIEW_OPENING.md) 选用头像模式；豆包为面试官，二哥为求职者，用户另有角色指定时优先遵从。

## 字幕

- 一次只显示一行，`whiteSpace: nowrap`。长句按完整语义分组后依次显示，保留原文顺序；不因为存在逗号、顿号或“地”就切换字幕。
- “英文全称 Reinforcement Learning，也就是强化学习”作为一组连续显示；“可以自信地、大方地、光明磊落地帮你搞清楚这三件事”不在“地”和“帮你”之间拆开。其他句子遵循同样的语义完整原则，不固定复用本例字数。超过单行可读宽度时，在自然语义边界拆分，不缩成难读的小字；字幕分组不要求重拆配音。
- 历史约定允许字幕隐藏 `——`；不能因此改写实际朗读内容。
- 字幕宽度只用于排版。具体切换点优先由真实配音定位，不凭分句单独重合成的时长拼估。
