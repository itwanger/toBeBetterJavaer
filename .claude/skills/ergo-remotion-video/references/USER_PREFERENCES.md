# 用户偏好

本文件维护内容与视觉偏好；目录和命令以 [共享工作流](../../../../docs/src/ai/script/shared/WORKFLOW.md) 为准。

## 项目与验收

- 共用配置、工具、组件放 `script/shared`；每条视频的原文、稿子、图片、音频、动画、试听、时间轴和成片集中在自己的主题目录。
- 项目 `project.json` 保存实际采用的配置。修改共享默认值不会改变旧项目；用户明确要求同步时才更新旧项目。
- 用户逐章验收，回复「继续」推进下一章；明确要求「渲染 / 出片」才导出 MP4。已授权就继续，不重复索要许可。
- 不固定章节数、配音段数或视频时长。KV Cache 的 69 段是旧项目数据，不是模板规范。

## 内容和朗读

- 用户确认的稿子按原文读，不自动加情绪、反问、语气词，也不批量改写数字。
- `text` 保留字幕原文；`ttsText` 表达用户明确指定的读法。
- 「需要的可以来个222」中的 `222` 读「二二二」；「288 道」读「二百八十八道」，字幕仍保留数字。
- 修改读法只重做受影响的配音单元，再更新处理音频和时间轴。
- 完整意群是新配音单元的起点；短自然段可以合并。一段音频包含多个动画动作和字幕片段是正常情况。
- 音色与倍率以当前项目配置及用户最新要求为准，不能把历史 1.10、1.15 等写成永远最佳值。
- 「3 分钟」可按稿子保留，实际时长以生成音频为准。

## 视觉与人物

- 动画为主，避免长段文字堆屏。金句、对话、术语可用大字卡片。
- 白底黑边圆角卡片、克制配色、顶部章节条、底部单行字幕；字号服从版面，不遮挡章节条或底部区域。
- 连续场景持续挂载；元素一次入场后稳定显示，不循环脉动，不逐句重播入场。
- 原稿配图原样使用；图片不加无关扫光、旋转或重新生成人物。
- 默认人物位于 `script/shared/assets/ergo-avatar.jpg`，项目副本在 `assets/images/ergo-avatar.jpg`。当前为用户提供的黑框眼镜、黄衬衫、黑领带形象。
- 圆形头像使用 `objectFit: cover`、`objectPosition: center top`，以脸和头发完整为准；完整人物图使用 `contain`。
- 二哥自介按稿子，不额外添加 `HOST` 英文标签。
- 机械/物理示意使用 SVG 或 div；横向运动图标方向与运动一致。

## 字幕

- 一次只显示一行，`whiteSpace: nowrap`。长句分成短语后依次显示，保留原文顺序。
- 历史约定允许字幕隐藏 `——`；不能因此改写实际朗读内容。
- 字幕宽度只用于排版。具体切换点优先由真实配音定位，不凭分句单独重合成的时长拼估。
