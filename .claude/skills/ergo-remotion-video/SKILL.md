# 二哥风格 Remotion 视频

本 Skill 只记流程节点和禁令。目录、命令、组件清单和素材清单统一在 [共享工作流](../../../docs/src/ai/script/shared/WORKFLOW.md)，画面偏好在 [用户偏好](references/USER_PREFERENCES.md)。

按已有经验直接制作，用户负责审片，提出要调整的地方再改。不额外扩展成逐条审稿；涉及具体公告、报告结论或测试数字的镜头，先找对应的一手证据再制作。交付时只说做了什么、哪里需要用户注意。

制作真实界面标注、输入发送或原图机制动画时，对照[已认可第一章样例](references/APPROVED_CH1.md)的成帧与源码，按[用户偏好](references/USER_PREFERENCES.md)选择载体和布局；样例用于理解视觉取舍，不要求所有视频复刻同一构图。

制作原文证据接数值对比、截图阅读与连续聚焦镜头时，参照[已认可第二章样例](references/APPROVED_CH2.md)，尤其检查先框原文再展开数据、图文分栏与原文有效字号。

## 定位项目

1. 从仓库根目录定位 `docs/src/ai/script/`，工具的 `--project` 传项目目录。
2. 继续旧项目先跑 `doctor.py` 看 `progress`，再读 `script.md`、`beats.json`、`OUTLINE.md`。
3. 找不到路径时修正路径，不新增另一套配置、依赖或生成目录。

## 流程节点

每个节点得到对应的用户回复后，用 `progress.py --mark` 记录。

1. **整理用稿**。写项目 `article.md`、`script.md`、`beats.json`、`OUTLINE.md`。文末公众号推广尾段连同后面的图片整段删掉，正文里的资料领取（288 道、222）和结尾点赞关注保留，源文章不改。原稿“视频封面”区块里的横版 16:9 封面（标题写“16:9 封面”或“宽屏横版封面”）下载为 `assets/images/cover-16x9.png` 做整片首帧。
2. **用户确认口播稿**，标记 `script`。确认前不合成配音。确认后按稿子制作，画面配合稿子讲。发现稿子和现行版本对不上，一句话告诉用户，由用户决定改不改。
3. **配音**。`pronunciations.py --write` 套用读音词典，再 `gen_audio.py`、`gen_cues.py`、`review_audio.py`（生成逐词对齐）。标记 `audio`。
4. **逐章制作**。先区分本章的事实证据与原理示意，按下方规则准备素材，并参照用户偏好的[场景构思](references/USER_PREFERENCES.md#场景构思)选择表达方式；再写 `ch<N>-spec.json`、生成时点和 `Chapter<N>.tsx`，跑 `chapter_pipeline.py`。工具报出的开口空画面处理掉，然后把 Studio 中的 `Chapter<N>Preview` 交给用户。逐章审片只用 Studio 预览和必要的静帧检查，不导出章节 MP4，也不以“备用”“验证”或“保险”为由额外导出。用户回复“继续”标记该章，再做下一章。
5. **出片**。只有用户明确要求“出片”或“导出视频”时才标记 `render` 并导出 MP4，整片渲染加 `--detach`。
6. **成片检查**。跑 `verify_export.py`，并从最终 MP4 抽帧复查封面、章节衔接、关键状态变化与片尾；检查因果表达和结果停留时间，通过后标记 `verified`。交付的是 `output/<outputName>`。
7. **纳入 Git**。`output/` 顶层只放最终 MP4，规则见 [成片版本管理](../../../docs/src/ai/script/shared/WORKFLOW.md#成片版本管理)。commit 和 push 只按用户明确指令执行。

## 禁令

- 预览用完就关闭本次对应的 `agent-browser` 会话；完成、失败、取消或用户说“不用了”时均执行，并核实会话及其浏览器进程已退出。会话归属、关闭命令与保留条件见 [预览浏览器](../../../docs/src/ai/script/shared/WORKFLOW.md#预览浏览器)。
- 密钥只从 `config.volc.apiKeyEnv` 指定的环境变量读取，不写进项目、Skill、日志或命令参数。
- 不手改 `build/` 下的生成文件，不按字数估算时长。配音变化后重新生成时间轴和混音。
- 用户指定音色或语速只改当前项目配置；修改共享默认值、共享组件或读音词典，不批量重做旧视频。
- **定稿脚本不得擅改**。用户提供的已定稿脚本是制作依据；源稿、项目用稿、`beats.json` 中的口播与字幕均不得自行增删、改写或调整顺序。即使为了事实修正、表达优化、时长或画面节奏，也必须先说明拟修改的原句、改法与原因，取得用户明确同意后再改；“继续”“下一章”或“出片”不代表同意修改脚本。发现证据与脚本不一致时先告知用户，由用户决定。
- 配音按确认稿朗读，不自动加语气词。`text` 是字幕原文；`ttsText` 仅用于读音调整，不得借此改动内容或含义。用户指定的读音修正按其指令执行。
- 没有实际试听，不说读音已验收。
- 使用原稿配图时保持原样，不用简化图形替换，也不重新生成；事实镜头优先采用对应的一手素材。带边框时取景框和图片同宽高比（`fitBox`），边框里不露空白。
- 自制画面的颜色只从共享色板 `C` 取，卡片只用共享 `card` 或 `Card`；真实截图、论文与官方图表保留原色。
- 录制还原的界面文字、顺序和数字只取自录制，没录到的不补，两次录制不拼成一次。录制只在临时目录里跑。
- 录制、调用 API、翻安装包或源码核对这类实操验证，先问用户。需要调 API 时用 DeepSeek，不调用 Anthropic API。
- 不伪造品牌标志和硬件产品图，先用共享素材库，见 [品牌素材复用](../../../docs/src/ai/script/shared/WORKFLOW.md#品牌素材复用)。

## 事实证据与原理示意

- 知乎资料直接用 Codex 内置浏览器访问；需要登录时告知用户，由用户导入 session 后继续。具体做法见 [官方证据素材](../../../docs/src/ai/script/shared/WORKFLOW.md#官方证据素材)。
- 讲“官方发布了什么、报告写了什么、测出了多少”时，主动查对应官网、原论文或官方仓库，展示真实网页、原文页段或官方图表；品牌标志、手绘卡片、箭头和大数字不能充当证据。搜索摘要只用于定位，不能当作出处。
- 通过原始页面或原图建立依据，再按配音放大关键句或标出图中数据；保留原文中的日期、版本、实验条件、“约”“初步结果”和数值区间等限定。出处信息保存项目记录，不另外在截图外加来源行；画面只留辨认对象与数据所需的标注。做法见 [官方证据素材](../../../docs/src/ai/script/shared/WORKFLOW.md#官方证据素材)。
- 解释机制、教学类比和算式时继续用动画；示例概率标明是示意，容量计算标明是估算，不冒充某个模型的真实输出或实测结果。不要把所有原理动画都换成网页截图。
- 找不到支持当前说法的一手证据，或原文与确认稿不一致时，明确告知用户，不用自画图补出“证据”，也不擅改配音。用户明确保留口播时，如实展示原始证据及完整限定，并在项目记录中保存出处和该选择。
- **证据接原图，英文配对照**。逐项讲解且已有合适原图时，优先用官方原文建立依据，再回原图按口播圈选；英文关键段另配简洁中文对照与关键词划线。具体取舍见[证据与原图衔接](references/USER_PREFERENCES.md#证据与原图衔接)。

## 音画规则

- **配音单元**。beat 按完整句子或自然意群拆分，一个 beat 里可以切换多组字幕和动画。选择题的问句和选项合成一个单元。细节见 [音画对齐](references/AV_SYNC.md)。
- **读音**。先查 [读音词典](../../../docs/src/ai/script/shared/config/pronunciations.json)，用户指出的误读和指定的读法直接改并更新词典。Git 统一按单音节 /ɡɪt/；标准读音、已通过试听的完整句子和适用音色分开记录，失败提示从共享候选与自动替换中移除。依据与复检见 [Git 读音规范](references/VOLCENGINE_TTS_GUIDE.md#git-读音规范)。其余方法见 [TTS 使用约定](references/VOLCENGINE_TTS_GUIDE.md)。
- **画面跟着配音走**。元素按配音提到的先后入场，在术语起音前 4 到 6 帧开始，之后稳定显示。每句话一开口主体区就要有相关内容。讲同一画面的相邻 beat 共用一个场景。
- **按完整意思安排镜头**。同一段机制优先保持连续场景，用高亮与状态变化推进；源码适合直接解释当前要点且能读清时仍可展示，不为每句话强插源码镜头。代码操作优先让变化发生在同一工作区的具体文件上，见[场景构思](references/USER_PREFERENCES.md#场景构思)。
- **字号与字重**。新制视频按已确认的[字号与手机端可读性](references/USER_PREFERENCES.md#字号与手机端可读性)排版：常规对象标签 34px、分组标题 40px / 字重 600，字幕独立保持 39px；不要把全部主体字都放大加粗。制作前核对复用组件的实际字号，放不下时减字、分组或聚焦，不缩小文字硬塞，也不批量重做已交付视频。
- **默认不叠加画外小标题**。截图、导航和字幕已说明内容时，直接呈现主体；具体取舍与删标题后的布局见[版式](references/USER_PREFERENCES.md#版式)。用户指出一处时，回看本期全部章节的同类镜头。
- **不新增画外出处**。截图、录屏、插图之外不再加网站、作者、发布日期、版本或“原文 / 定价例子”等来源行，顶部和底部都不加；不得以“必要身份”为由另造窗口标题。原始素材自带的内容保留，出处与验证信息写入项目记录；只有用户明确要求才另加出处标注。
- **先验收文字取舍，再验收字号**。主体只保留辨认对象、区分选项与读取数据所需的文字。配音已解释的关系、公式和结论，用对象动作表达，不补成短句贴在画面上；逐项检查新增文字及其用途，并把实际删减与保留理由写入审片记录，详见[画面文字取舍](references/USER_PREFERENCES.md#画面文字取舍)。
- **段位直接进阶梯**。闯关段落从口播开头就显示阶梯与登阶动作，省略头像加旗帜的闯关提示过渡；同一期各段位统一处理，见[闯关稿](references/USER_PREFERENCES.md#闯关稿)。
- **真实操作与连续对照**。讲 Agent 产品具体操作时，优先采用授权后的真实终端素材；原理讲解继续用动画。双会话比较优先固定两窗同屏，先全貌、再共同推近一次，给结果留出稳定阅读时间，再切换产品；不要在短句中反复切窗和重置镜头。素材与节奏细节见[真实录制演示](references/USER_PREFERENCES.md#真实录制演示)。
- **开源知识库沿用固定展示**。介绍王二讲 Agent 开源知识库时，默认左侧本期主题加二哥，右侧真实知识库录屏；先全貌，再按口播缓慢浏览，相邻自介与资料介绍共用连续场景。版式和共享素材见[开源知识库展示](references/USER_PREFERENCES.md#开源知识库展示)。
- **原稿配图**。在 `OUTLINE.md` 里写清每张图对应的场景、beat 和聚焦顺序。
- **提示音**。默认开启，只标少量有意义的变化，音量低于配音。用户说不要时关闭。

稿子里有“面试官问你”或面试追问时，读 [面试头像开场](references/INTERVIEW_OPENING.md)。普通科普稿不加面试剧情。

## 组件和素材

- 先用共享组件，清单见 [共享场景组件](../../../docs/src/ai/script/shared/WORKFLOW.md#共享场景组件)，新章节从 `shared/remotion/examples/Chapter.example.tsx` 复制起步。
- 同一个场景或图标两期以上重复手写、且不含主题数据时，提升到共享组件并登记。
- 品牌图标、面试头像、提示音在 `shared/assets/`，用前复制到项目 `assets/images/`。
- 组件代码按 JSX 元素换行，单行不超过约 160 个字符，样式常量放在文件顶部。
