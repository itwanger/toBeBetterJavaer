# 孟菲斯：可选画风

用户选择“孟菲斯”时读取本页，并参考[已确认的勾股定理案例](approved-memphis.md)。暖米几何仍是默认；已有项目沿用用户确认的风格。两种画风共用文稿、配音、字幕与阶段流程，不为换画风重生成已认可的声音。

## 来源与案例状态

灵感来自[Regen的原帖](https://x.com/huqinyiyayuguan/status/2114717415942783384)。2026-10-31实际查看其约20秒视频的5、10、15秒画面：浅纸底、粉彩几何、靛色轮廓、局部点线纹理，以及遮挡后显露的空间关系。参考视频的城市、建筑、角色、配乐与小字信息不搬入科普片。

2026-11-01用户确认了本系列孟菲斯版的开场、拼图表达与最终配色。下列规则来自这几轮实际返修；完整成帧及检查范围见案例页。已确认的是预览画面，公开工程提供无声动画，未把它标为正式有声MP4。

## 首帧与前两秒

- 第一帧就呈现与当前知识点有关的完整彩色主体和简短主题，具有清楚的体量、轮廓和构图；不要先以少量线稿等待后半片才进入孟菲斯画风。
- 前1–2秒用一次有教学目的的选取、拼合、展开或遮挡—显露，把目光带到正在讲的对象，再停稳供理解。开场的材料、造型与正文连续，不能只有片头多彩，讲解又退回另一套画风。
- 勾股案例先展示完整拼图，再抽出直角三角形。其他题材应使用自己的知识对象：容器与受力物体、光线与介质、粒子或生物结构。四块拼图、四字题格、两行标题及本例坐标都不是通用模板。
- 检查首帧、拆分中段、2秒附近和正文落定状态。标题字块与主体路径避免互相穿越，不能靠无关装饰或随机漂浮填满画面。

## 配色的层级

基础色板见[随包资产](../assets/styles/memphis-palette.ts)。复制到当前项目使用，不修改共享暖米色板`C`。

| 角色 | 基础色 |
| --- | --- |
| 结构轮廓、正文、字幕底 | `ink` `#25214A` |
| 主体、标题和拼片色面 | `yellow` `#FFC93C`、`pink` `#FF8DB5`、`mint` `#A9E6C6`、`lavender` `#D3BEFF` |
| 数据与必要身份色 | `coral` `#FF5A5F`、`cobalt` `#2E5BE6`、`sky` `#8DD3F6` |

- 先建立浅色面与统一靛色轮廓，再让粉彩标签、公式项和不同物体表达身份。单个主体不要同时堆上强烈填色与多种鲜色边线；确需彩边区分对象时，说明其语义并跨镜保持。
- 主体色面可从参考色混入纸底，保持粉彩质感。已确认案例将`M.mint`与25%的`C.bg`混合，得到`#BDE9CF`；三条边统一靛色，讲到对应边时用线宽强调。这个薄荷三角形是案例选择，不要求化学、生物或其他图形一律用绿色。
- 身份应在标签、所属物体和公式之间持续可辨；填色、文字与轮廓可以承担不同角色，不要求每一条轮廓和每一个字都同时使用身份色。标签上的文字优先用靛色保证可读。
- 彩色要参与讲解：公式项可以有对应的纸片底，面积方格有真实填色。字号、计数和阅读层级优先，不能把整套颜色平均铺到每一条边和每一处空白。
- 成功/正确仍需明确状态表达，不能仅凭浅绿色让观众推断结果。

## 材质、轮廓与拼接

- 少量选定色面使用疏点或条纹，其余保留纯色。单位格、计数粒子、细胞边界等可能被误数的对象上不铺装饰点。减少海报内框和重复碎形，留白服务主体。
- 纹理绑定物体局部坐标或顶点，随物体平移和旋转。固定种子并稳定缓存，任意跳帧可重现同一状态；不能用不断重采样的世界网格让图案在物体里游动。
- Canvas绘制纹理后须重新建立物体轮廓再描边：`save/restore`不保存当前路径，直接`stroke()`可能只描到最后一个纹理点。以实际中间帧检查接缝，不能只看填色。
- 面积证明中的落定拼片平贴，不保留挤入待比较面积的阴影。抬起移动时可用短暂、同向、无模糊的偏移投影，落下后消失。其他非计算色面可按材质需要保留投影，但不能改变对象的可见边界或造成假缝隙。
- 方格从源位置搬走后，原处只留空轮廓，不留下同一份填色副本。拼片用刚体运动，示例参数变化时重算真实几何。

## 标记与字幕安全区

- 以整个标记容器检查避让，计入内边距、边框和阴影；文字字面没有压线，不代表标记框没有压线。
- 根据当前几何和相机计算标记位置，同时给图形外侧与字幕上方留出空间。放不下时调整构图或统一缩放主体，保持几何比例；不能只把底边标签向上挤进三角形。
- 中文边名变为数学字母时，重新检查完整容器。相机缩放会让原来安全的框移入主体；应在缩放前退出或重排标记框，再由文字标注接手，避免容器穿越边线。
- 延续[手机视觉规范](visual-style.md)的48px标签/字幕、60px数学符号和84px常驻公式。本例开场使用114px题字、100px临时公式，属于构图取舍，不是每条片的强制字号。
- 字幕在世界相机之外。原尺寸、约390px信息流缩图与740px横屏缩图都检查，尤其看最长字幕、上标、底边标记和拼图中间状态。

## 接入与验收

复用Canvas/Remotion与随包`MO/DG/CAM`，不宣称适配器有完整画材引擎。分镜和`visual-provenance.json`记录风格、色板派生方式、纹理绑定及动作实现。

先检查重要过程的起点、中段与落定帧，再看正常速度播放；把整框避让、字幕安全区、运动连续性及未验证项写入`review.json`。案例中的约19px图形间距、约53px字幕间距和抽帧数量是本例证据，不固化为其他项目必须复刻的数值。样例、动态预览、正式导出、用户认可分别记录，不把某一项检查成功当成全部通过。
