# 手机观看的视觉规范

2026-10-31用户认可的[勾股定理样例](approved-pythagorean.md)是本系列的起点。延续二哥的暖米色、语义色和文字层级；本系列手机字号优先于长片的34px标签、39px字幕。用户另有明确要求时按该次要求，不批量重做旧视频。

## 画风选择

提供三种画风：**暖米几何**为默认，**[孟菲斯](style-memphis.md)**与**[超级玛丽](style-super-mario.md)**为用户可选。已有项目沿用已确认的选择；新项目未指定时直接使用默认，不额外要求选风格。选择孟菲斯或超级玛丽时，场景轮廓与物体填色改用对应独立色板；本页的标题、字号、语义字幕和手机验收仍适用。颜色部分的共享`C`规则是默认画风，不覆盖用户明确选择的其他画风配色。超级玛丽仅将角色、环境和界面边缘像素化，中文字幕与科学图形保持清晰；具体语义与动作规则见风格卡。

## 标题与字号

标题只写当前知识点，例如“勾股定理”；项目标题、frontmatter、片头和简短主题标识一致。不自动加“Vibe知识大赏”、期数、“什么是”或问号，系列名是工作流名称，不是每条画面的前缀。

以下是1920×1080横版的默认起点，字号按最终画面中的有效尺寸检查：

| 用途 | 字号与字重 |
|---|---|
| 左上简短主题 | 36px，常规 |
| 开场主标题 | 88px，600 |
| 中文对象名、普通数字、拼图编号 | 48px，常规 |
| 数学变量、面积符号 | 60px，CMU常规/数学斜体 |
| 核心公式、需要突出的结果 | 84px，常规 |
| 底部字幕 | 48px，约500，单行 |

中文及普通数字标签复用共享`LABEL_FONT`，字幕复用`FONT`并确保字体加载完成；等宽字体只给代码或命令。数学保留CMU，变量斜体属于数学排版，中文不斜体。CMU的字面高度较小，因此数学标签使用60px作视觉补偿，不把所有文字设成同一字号或全部加粗。

已确认的[孟菲斯案例](approved-memphis.md)开场使用114px题字和100px临时公式，常驻公式仍为84px；这是该例构图取舍，非通用固定值。

统一保存在项目的字号常量中，方便整条调整。放不下时先减少重复文字、重排对象或按语义分组，保持几何比例；不要通过缩小整个容器让设定字号失效。其他画幅重新布局并按实际阅读尺寸验收，不把横版画面缩进竖屏后仍声称适配。

## 默认暖米几何的颜色与空间

- 颜色直接取共享`C`：`bg`暖米底，`ink`正文及字幕底，`card`浅底/字幕字，`blue`主色，`rust`强调和对比，`gray`次要信息。`green`只表示正确或通过，不随意增加语义色。
- 对象、所属标签和公式中的同一符号保持一致的身份色。勾股例中a为rust、b为blue、c为ink；这是该例映射，不是其他学科的通用变量配色。
- 面积和大块背景优先用低浓度身份色。无独立身份的剩余区域可取`C.track`等共享中性色，避免所有大面都用深色抢走文字层级。不要另造近似色。
- 直接演示物体或几何图形时不额外套卡片。移动拼图需要抬起感时可暂用`C.shadow`无模糊偏移；静止后回到干净轮廓，阴影不改变几何计算。
- 按主体最下沿计入标签、描边、阴影与运动范围，距字幕通常留48–64px。公式上标也计入顶部主题或进度线的间距。放大文字后检查边名是否压到边线、维度标签是否掉进字幕区，以及对照入场是否相互重叠。

## 整框边界与转场

标记按整个容器（文字、内边距、边框、阴影）相对实际几何检查，不能仅看字面或基线。依当前相机从图形边界计算位置，分别预留图形外侧和字幕前的空间；必要时调整构图并保持几何比例。检查中文转字母、起始/中段/落定状态和镜头缩放。原位置在缩放后会压线时，先退出或重排容器，再让文字标注接手。

## 字幕与手机检查

字幕用`C.ink`深底、`C.card`浅字，`whiteSpace: nowrap`。完整语义内一次显示一行，长句按自然意群依次出现，顺序及全部原文字词保留。例如：

```text
两个小正方形分别有9个和16个单位方格，
→ 把它们全部搬到斜边上，
→ 正好铺满大正方形的25个方格。
```

此处展示分组方式，实际字幕必须保留源稿的空格和标点；箭头不是字幕内容。分组依据逐词对齐，不平均分配时长，不为分组重切完整配音意群。

先查看原尺寸的起始、中段、落定帧，再检查约390px宽的信息流缩图和约740px宽的手机横屏缩图；这是两种阅读尺度，不是新的导出尺寸。优先抽查最长字幕、最小图形、公式上标、拼图运动与并排对照。字幕仍过密时继续按语义分组，别退回小字。

在项目`review.json`记录实际字号、保留文字及其用途、手机缩图、溢出/遮挡、字幕间距和动态检查结果。缩图和自动边界检查不能代替正常速度播放，也不冒充真实手机设备测试。样例的帧数、抽帧数量和具体间距是证据，不作为每条片必须复刻的数值。
