# AI 公众号标题指南

## 顺序

全文写完并完成事实检查后再定标题。先提取正文中最强的一手事实、对读者最直接的结果和最有价值的作者判断。

## 六种信息结构

- 模型发布：`[模型/版本状态] + [最值得关注的变化]`
- 价格变化：`[核心产品 + 可核验数字变化] + [用户直接收益]`
- 双事件：`[主体 + 精确数量 + 动作] + [同日第二事件]`
- 行业声明：`[精确人数/数量 + 原始动作] + [克制判断]`
- 官方方法论：`[权威主体 + 反常识动作 + 数字] + [核心概念变化]`
- 事件复盘：`[利益或冲突 + 产品 + 数字倍率] + [事件或机制复盘]`

公式用于组织信息，不用于复制“杀疯了”“笑死我了”“来了”“有点夸张”等固定措辞。

## 事实红线

- 数字指向谁，标题就写谁。system prompt 减少 80%，不能写成 Skills 减少 80%
- 账号数量不能写成人数；员工个人签署不能写成公司联合表态
- 两件事同期发生，不得暗示因果
- 评论截图不能扩大成“全网都在”
- 没有实际测试，不能写“我测了一天”“我熬了一夜”
- “最强”“全面领先”“杀疯了”必须有口径一致的充分证据，否则改写为具体变化
- 版本名、时间和精确数字必须能回到一手来源
- 标题不能承诺正文没有交付的教程、源码、数据或结论

## 五个候选角度

每次生成且仅生成以下五类，不做同义词替换：

1. 直接新闻型：最快说明发生了什么
2. 数据结果型：突出最强且可核验的数字
3. 反常识判断型：强调旧认知被哪条证据改变
4. 读者收益型：说明开发者或普通用户能得到什么
5. 克制专业型：减少情绪，突出技术或机制价值

推荐其中 1 个，用一句话说明它兑现了正文中的哪条证据。标题尽量控制在 60 字以内，但准确性优先。
