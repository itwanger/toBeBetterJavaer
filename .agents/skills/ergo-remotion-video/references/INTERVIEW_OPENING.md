# 面试头像开场

用于已有面试情境的口播。先根据稿子判断有哪些动作，再选用下面的表现方式；不要为套模板补写错误答案、“回家等通知”或其他台词。

## 角色与构图

- 当前选定的组合：左侧豆包头像担任面试官，右侧二哥头像担任求职者。用户指定其他角色时优先遵从。
- 仅显示头像及简短角色名，去掉身体、桌椅和并排坐的全身人物。头像处于左右相对的位置，中央留给主题动画。
- 二哥使用用户原头像衍生的朝左版本，保留黑发、黑框眼镜、黄衬衫。豆包使用基于官方头像调整的朝右版本，与二哥视线相对；保留豆包原本的短发、卡通脸和黑色上衣，不替换为写实商务头像。官方原图作为参考保留；朝右版本是本项目生成的衍生素材，不称作官方侧脸图。
- 发言或思考时用对应头像的边框高亮、定向箭头或思考气泡说明归属；没有逐音素口型数据时，不做假口型或循环抖动。
- 顶部可用当前章节名和细进度条，给开场留出空间。整套章节目录可以在章节切换处出现。

## 按语义组织画面

| 稿子中的动作 | 画面职责 |
| --- | --- |
| 面试官提出问题 | 面试官头像高亮，中央出现问题对象、术语或关系示意；完整问句放底部字幕 |
| 求职者给出错误猜测 | 求职者头像高亮，思考气泡呈现猜测的图形含义；明确标为“错误猜测”，避免被误认为知识结论 |
| 否定或指出概念混淆 | 在对应关系上划叉或出现简短纠错提示；不要重新抄写整句回答 |
| 稿中有请离场的玩笑 | 求职者头像向外移动或淡出，辅以出口箭头、简短结果；不新增全身行走场景 |
| 短追问“为什么？” | 延续前一组概念，聚焦尚未解释的关系或问号；不同时显示两份“为什么”大字 |

这些是可选动作，不是必须凑齐的五个镜头。同一场景可以承接几条字幕。更换主题时重新设计中央动画：KV Cache 的 Q/K/V、放大的 Q、key/value 是本题示例，不是通用背景。

## 素材与代码

共享素材位于 [shared/assets/interview](../../../../docs/src/ai/script/shared/assets/interview/)，使用前按 [WORKFLOW.md](../../../../docs/src/ai/script/shared/WORKFLOW.md) 的“面试开场素材”约定复制到当前项目 `assets/images/`。来源及用途见素材目录的 `sources.json`。不依赖旧视频目录中的素材或试听文件；不把配音放进 Skill。

头像组件为 [InterviewAvatar.tsx](../../../../docs/src/ai/script/shared/remotion/components/InterviewAvatar.tsx)，只接收图片地址、名称、角色、强调色与高亮状态。例如项目 `remotion/src/` 中：

```tsx
import {InterviewAvatar} from '../../../shared/remotion/components/InterviewAvatar';
// staticFile 来自 remotion；高亮状态来自本项目真实时间轴。
<InterviewAvatar src={staticFile('images/doubao-facing-right.png')}
  name="豆包" role="面试官" active={interviewerSpeaking} accent="#3665e8" />
```

父场景负责左右位置、中央动画与进退场，公共组件不加载某个项目的配置或台词。

## 音频和验收

- 两个头像是剧情角色，不意味着必须使用两种声音。沿用用户为该项目指定的配音，除非用户要求分角色配音。
- 先获得当前音色的实际音频，再定位短语和动作。更换音色或倍率后重建音频时间轴并复核短语边界；不要照搬旧样片的 13.7 秒、五段 TTS 或固定帧数组。
- 初次尝试这个模式时，先做用户指定的开场范围供查看，再按用户反馈扩展。已请求制作或更新的样片可以完成导出和交付，不因此扩大到整片重做。
- 复检主体与字幕是否互补、角色是否清楚、错误示意是否有标记、头像是否裁掉头发或遮挡内容，以及新配音是否仍与字幕和动作对应。复用不等于免于检查。
